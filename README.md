## WELCOME TO FTC APEX!

This Repository contains the SDK for the FIRST Tech Challenge Team 24513, APEX Robot for the 2024-2025 Season, INTO THE DEEP.

## REQUIREMENTS:

* Android Studio Ladybug Feature Drop
* The APEX Robot

## NAVIGATING THE SDK

This SDK is divided into two portions, the [TeamCode](https://github.com/KrishKalla/IntoTheDeep2025/tree/master/TeamCode/src/main/java/org/firstinspires/ftc/teamcode) Folder, and the [PedroPathing](https://github.com/KrishKalla/IntoTheDeep2025/tree/master/TeamCode/src/main/java/pedroPathing) Folder.

The TeamCode Folder holds all of the robot OpModes, subsystems, and utilities. This is the Main folder where changes will be made.

The PedroPathing Folder holds a modded version of FTC Team 10158: Scott's Bots' Path Follower, Pedro Pathing. Within it contains all the files for pathing, the localizer, and constants from tuning.
